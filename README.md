# CPU & CUDA Ray Tracer

A 3D renderer based on ray tracing, implemented with two backends: multithreaded CPU and GPU (CUDA). Developed as a coursework project at University.

## Overview

The goal of this project is to implement a physically inspired ray tracer and compare the performance of CPU and GPU implementations of the same algorithm.


## Requirements

- C++20-compatible compiler (GCC / Clang / MSVC)
- CMake >= 3.18
